### 0.3 十条**口径**——不遵守会得出不同结果（**最重要的一节**）

以下选择**都会改变结论，但都不会报错**。这是本研究最容易出错的地方：

| # | 口径 | 必须怎么做 | 做错的后果 |
|---:|---|---|---|
| 1 | **二值栅格聚合** | 块内取 **max** | 用众数会把道路抹平（实测 hir 从 127,343 像元降到 **3** 个），致**生境质量趋势方向反转** |
| 2 | **DI 归一化** | 各分量**除以自身均值** | 用 min-max 得 ERI 0.006（应为 0.047） |
| 3 | **景观指数公式** | 论文原式 `C=n/A`、`N=√(n/A)·(A/A_i)` | 用其他形式位次相关只有 0.068（应 0.985） |
| 4 | **空间统计对象** | **9 km 评价单元** | 算在克里金面上得 0.9966（应 0.5616） |
| 5 | **中心性度量** | **Conefor PC（含斑块内项）** | 用连通性下降会**完全反转**排序 |
| 6 | **MSPA 前景** | 二级分类 + **FVC≥0.3 拆草地**、排除裸地 | 用一级类会致核心区只剩 1 块（应 516） |
| 7 | **Hurst** | 标准 R/S + **截断 [0,1]** | 不截断会得「正持续 100%」 |
| 8 | **产水总量** | `水深(mm) × 面积(m²)/1000` | 论文口径**少算 10.11 倍** |
| 9 | **碳密度单位** | **t/ha** | 论文输出实为 t/像元，差 **11.111 倍** |
| 10 | **数据路径自适应** | 用 `find_pkg_root()` 自动定位 | 写死盘符会在换机后全盘失败 |

## 软件

Python（numpy 逐像元运算）**或** ArcGIS 的 Raster Calculator

## 公式与参数

| 项 | 公式 / 取值 |
|---|---|
| **潜在侵蚀** | `Ap = R · K · LS` |
| **实际侵蚀** | `Ar = R · K · LS · C · P` |
| **水土保持量** | `SC = Ap − Ar = R·K·LS·(1 − C·P)`，**最后钳到 ≥0** |
| **K（EPIC）** | `K = K_EPIC × 0.1317`（美制转国际制） |
| **C（蔡崇法）** | `C = 0.6508 − 0.3436·lg(100·FVC)`；FVC ≥ 0.783 时 C = 0 |
| **P（8 级赋值）** | 水域/冰雪 0.00 · 森林 0.20 · 灌木 0.50 · 农田/湿地 0.60 · 草地 0.70 · 裸地 0.90 · 不透水 1.00 |
| **单位** | 结果单位 **t/(ha·a)**；像元面积按网格实际值（30 m 用 900 m²，300 m 用 90000 m²） |

## 操作步骤

① 逐年读取 5 个因子，逐像元相乘得 Ap 与 Ar

② `SC = Ap − Ar`，**注意钳到 0**（float32 舍入会产生 −1e-4 级负值）

③ 统计逐年均值与总量

④ **与论文表3-1 逐项核对**：2000 年平均侵蚀应为 **36.33**、平均保土 **134.01** t/(ha·a)

⑤ 聚合到 300 m 供后续使用

## 公式与参数

| 项 | 公式 / 取值 |
|---|---|
| **产水量（Zhang 曲线）** | `AET/P = (1 + ω·PET/P) / (1 + ω·PET/P + P/PET)` |
| **ω 参数** | `ω = Z · AWC/P + 1.25`，其中 **Z = 1.2**（本研究反推） |
| **产水量** | `Y = (1 − AET/P) · P` |
| **PET** | `PET = Kc × ET₀` |
| **AWC** | `AWC = Min(根系限制层深度, 根深) × PAWC` |
| **水源涵养总量** | **`总量(m³) = 水深(mm) × 面积(m²) / 1000`**；1 mm = 10 m³/ha |
| **生境质量** | `Q_xj = H_j · (1 − D_xj^z/(D_xj^z + k^z))`，z = 2.5，k = 0.5 |
| **碳储量** | `C_total = Σ(C_above + C_below + C_soil + C_dead) × 面积`，单位 **t/ha** |

# 阶段 4　趋势与持续性分析

**目标**：对四类服务逐年序列做趋势检验与长程依赖性分析。

## 数据

| 文件/目录 | 说明 |
|---|---|
| `J:\黄河源区环境可持续能力_科研全流程\04_成果栅格\生态系统服务_300m\*.tif` | 四类服务逐年栅格 |

## 软件

Python（scipy + numpy）**或** R（可用 RStudio）

## 公式与参数

| 项 | 公式 / 取值 |
|---|---|
| **Theil-Sen 斜率** | 全部两两组合斜率的中位数（Sen 1968） |
| **Mann-Kendall** | `Z` 统计量；方差 `var = n(n−1)(2n+5)/18`，含连续性校正 |
| **显著性阈值** | **1.645 / 1.96 / 2.58**（90% / 95% / 99%） |
| **Hurst（标准 R/S）** | 把序列按 τ 分**非重叠子段**，回归 `log(R/S) ~ log(τ)`，**结果截断到 [0,1]** |

## 操作步骤

① 逐像元计算 Sen 斜率

② 逐像元计算 MK 的 Z 值，按 1.645/1.96/2.58 分级为 9 类

③ 逐像元计算 Hurst，**务必截断到 [0,1]**

④ 按 Hurst 分类：H>0.5 持续、H≈0.5 随机、H<0.5 反持续

⑤ **核对**：SC 的 Sen 均值 **3.892**、Hurst 均值 **0.781**、**H>1 占比必须为 0%**

## 软件

Fragstats（算景观指数）+ Python/ArcGIS（合成 DI 与 ERI）+ GeoDa/ArcGIS（Moran、LISA）

## 公式与参数

| 项 | 公式 / 取值 |
|---|---|
| **景观分维数** | `F_i = 2·ln(p_i/4) / ln(A_i)` |
| **景观分离度** | `N_i = √(n_i/A_i) · (A/A_i)` |
| **景观破碎度** | `C_i = n_i / A_i` |
| **景观干扰度** | **`E_i = 0.5·C'_i + 0.3·N'_i + 0.2·F'_i`**，**三分量须先各除以自身均值归一化（value/mean）** |
| **景观损失度** | `R_i = E_i × V_i`，Vi 取表2-12（等价于 `(分级−1)/8×0.14+0.03`） |
| **风险指数** | **`ERI_k = c · Σ_i A_ki · R_i`**（面积**求和**，**不减除单元面积**；c 为标定常数） |
| **Moran's I** | **在 9 km 单元上算，rook（四邻域）行标准化权重** |

## 操作步骤

① 用鱼网把研究区切成 **1,682 个有效 9 km 单元**

② **逐单元**算类级景观指数（C、N、F）—— 注意用论文原式 `C=n/A`、`N=√(n/A)·(A/A_i)`

③ 三分量**各除以自身均值**归一化，再按 **0.5/0.3/0.2** 合成 DI

④ `ELDI = DI × Vi`；`ERI = c·Σ A·ELDI`（面积求和）

⑤ 克里金插值得连续风险面（像元 900 m）

⑥ 在 1,682 个单元上算 **Moran's I（rook）** 与 **LISA**

⑦ **核对**：逐单元 ERI 均值 **0.047205**、克里金面均值 **0.0505**、Moran's I **0.5616**

`04_成果栅格\景观生态风险\`（11 个：ERI 面 / LISA / 莫兰统计）

**支撑 §5.1「景观生态风险空间聚集特征显著」**：Moran's I = **0.5616**（9 km 单元、rook 邻接、p<0.01）。

③ 按 **α=0.7** 与 AHP 权重组合

④ 加权求和得 ESCI

⑤ 自然断点分 5 级

## 工程打不开怎么办

`.mxd` / `.opju` 里保存的是**绝对路径**，而这些工程是历年不同机器、
**不同盘符**下做的（实测引用了 H: / F: / K: / E: / G: / J: 六个盘符）。换机后需重连：

```bash
cd 07_绘图工程
python reconnect.py --check    # 先看会改什么
python reconnect.py            # 批量重连（自动备份）
```

映射表与逐工程清单见 [`工程数据源重连清单.md`](工程数据源重连清单.md)。

- **确属原文错误的**（10 倍量纲、碳储单位等）→ **给正确值，不复制错误**

## 附：出问题时的排查表

| 现象 | 可能原因 | 解决 |
|---|---|---|
| `check_env.py` 报缺文件 | 数据未就位 | 对照报告里的「缺失」清单 |
| 有效像元数不符 | 掩膜版本不对 | 确认用 `03_过程数据/300m工作数据/grid/mask_300m.tif` |
| 保土量整体差 10 倍 | 像元面积用错 | 30 m 用 900 m²，300 m 用 90000 m² |
| 威胁栅格像元极少 | 二值栅格用了众数 | **必须用 max** |
| Hurst 出现 >1 的值 | 未截断 | 截断到 [0,1] |
| HQ 趋势方向相反 | 同「威胁栅格像元极少」 | 检查聚合方式 |
| 渔网单元数不符 | 未与掩膜取交 | 相交后应得 1,682 个 |
| 图中中文是方框 | 缺中文字体 | Linux 装 `fonts-wqy-zenhei` |
| `ModuleNotFoundError: repro` | 包路径未解析 | 确认 `06_文本/repro/` 存在 |
| `.mxd` 红叹号 | 数据源失联 | 跑 `reconnect.py` |
