# Data and code availability

- Analysis code, model parameter tables and the file manifest are archived at GitHub:
  https://github.com/<YOUR-GITHUB-USERNAME>/yrsr-reproduction
- Final result rasters (~1.1 GB) are archived at Zenodo with DOI: 10.5281/zenodo.<RECORD-ID>
- Raw inputs (~489 GB) and intermediate products (~116 GB) are not redistributed; their exact paths,
  sizes and dates are listed in `04_manifest/input_and_process_file_list.csv` so that the inputs can be
  re-assembled from the original public sources (see `00_docs/Reproduction_Manual.md`).
